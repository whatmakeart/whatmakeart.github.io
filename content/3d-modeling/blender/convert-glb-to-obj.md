Epic Games Reality Scan [photogrammetry](../photogrammetry.md) app exports `glb` model files. This file format works well in online browsers but sometimes a particular workflow needs an `obj` or other 3D file type. [Blender](blender.md) can convert many different 3D file types. This video shows how to convert a `glb` exported from Epic Games Reality Scan into an `obj`.
