Learn how to add, duplicate, position, and customize lights in [Blender](blender.md) to create more interesting 3D animation [renders](rendering-basics-blender.md). This beginner-friendly Blender lighting tutorial demonstrates how to view your scene using rendered viewport shading, move the default point light, duplicate lights, and change their colors.

It also shows how to add a Sun light, adjust its direction, control shadow softness, and increase its strength. Finally, the tutorial explores Blender’s World settings and Sky Texture for creating atmospheric global illumination in Eevee.

These simple lighting techniques are useful for [motion capture](../motion-capture.md) animations, character scenes, [basic environments](model-simple-scenery-blender.md), and other Blender projects that need more depth, visibility, and visual impact.
