Add simple scenery in [Blender](blender.md) using a ground plane and a few basic mesh objects. This beginner friendly tutorial shows how to turn an empty scene around a rigged character into a quick environment for [rendering](rendering-basics-blender.md) and animation.

Give the scene more depth. Add and scale a plane, create a cone, move objects into position, and duplicate props. These simple Blender modeling tools help you build a basic setting for animation with minimal effort.

Shortcuts covered:

- Shift + A: Add mesh objects
- S: Scale the ground plane
- G: Move objects
- G, then Z: Move along the vertical axis
- Shift + D: Duplicate props
