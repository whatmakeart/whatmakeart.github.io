## New Mesh Generation Tools

3D generative tools often improve and leap over pervious methods in capabilities. What was state of the art last month may be obsolete next month.

### Open Source 3D Generation Tools

#### Trellis 2

[Trellis 2](https://huggingface.co/spaces/microsoft/TRELLIS.2) is an open source 4 Billion Parameter 2D image to 3D and text to 3D Generator by Microsoft. It can be run in the cloud locally on a desktop or laptop computer without an internet connection.

- [Trellis 2 Demo on Hugging Face](https://huggingface.co/spaces/microsoft/TRELLIS.2)
- [Trellis 2 by Microsoft GitHub Repository](https://github.com/microsoft/trellis.2)

#### Hunyuan3D 2.1

Hunyuan3D 2.1 is an open source 3D generator and texture generator by Tencent. It is less cabable than their newer models but has open weights and can be run locally.

- [Hunyaun3D Demo on Hugging Face](https://huggingface.co/spaces/tencent/Hunyuan3D-2.1)
- [Hunyuan3D 2.1 on GitHub](https://github.com/tencent-hunyuan/hunyuan3d-2.1)

#### Spar3d

"SPAR3D is a fast single-image 3D reconstructor with intermediate point cloud generation, which allows for interactive user edits and achieves state-of-the-art performance." [^spar3d]

- [Spar3d on GitHub](https://spar3d.github.io/)

#### SAM 3D

- [SAM 3D by Meta](https://ai.meta.com/research/sam3d/)

#### StableGen

- [Stable3DGen Demo on Hugging Face](https://huggingface.co/spaces/Stable-X/Hi3DGen)
- [Stable3DGen on GitHub](https://github.com/Stable-X/Stable3DGen)

### Paid 3D Generation Tools

Paid 3D generative tools often offer free trials, credits, or free educational access.

#### Hunyuan by Tencent

- [Hunyuan3d Demo on Hugging Face](https://huggingface.co/spaces/tencent/Hunyuan3D-2.1)
- [Hunyuan3d Demo on Tencent Site](https://3d.hunyuan.tencent.com/login?redirect_url=https%3A%2F%2F3d.hunyuan.tencent.com%2F) 20 free credits with login. High fidelity 3d mesh and texturing from multiple images or from text prompts.

#### Autodesk FLow Studio

- [Autodesk FLow Studio](https://www.autodesk.com/products/flow-studio/) - Students can sign up for an Autodesk Education Account and receive Flow Studio Credits

#### Hi3D (Hitem3D)

- [Hi3D Demo](https://www.hi3d.ai/workspace)
- [Hi3D](https://www.hi3d.ai/)

#### Meshi.ai

- [Meshy AI](https://www.meshy.ai/) - Requires sign in but allows some generations
