## Overview

In the XR Studio, students use screenshots from films and other moving image media as visual references for composing virtual production shots. A shot is one continuous camera view. A cut is the transition from one shot to another. A scene may contain many different shots and cuts.

### 2. Add Rule-of-Thirds Overlays in Photoshop

The rule of thirds divides an image into nine equal rectangles using two vertical and two horizontal lines. These divisions can help you examine how subjects, horizons, and important visual elements are positioned within the frame.

1. Open a screenshot in Photoshop.
2. Use the Crop Tool to remove any interface elements or black borders that are not part of the actual image. Preserve the composition and original aspect ratio.
3. Select **View > New Guide Layout**.
4. Set **Columns: 3** and **Rows: 3**, with gutters and margins set to zero.
5. Create a new layer above the image.
6. Using the Line Tool, draw two vertical and two horizontal lines aligned with the guides. Use a visible stroke color and relatively thin lines.
7. Save a JPG or PNG copy with the four lines visible.
8. Repeat for your remaining screenshots.
