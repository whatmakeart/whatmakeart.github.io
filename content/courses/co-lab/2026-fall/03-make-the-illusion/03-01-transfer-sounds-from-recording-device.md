## Transfer Audio from Phone without Losing Quality

Whn mobile devices send media files through SMS, MMS, chat programs, and other transfer methods, the file is often compressed before transmission. This makes the file smaller and easier to send in a message but is bad if you want to edit the original file data. Best practice is to use the mobile devices file transfer tools to copy the exact media file without modification to an external file system such as cloud storage or directly to a laptop.

**Transfer the original file**

- Don't send a SMS or MMS text of the file. It will likely be compressed before sending.
- Don't send though social media
- Don't convert it to any other file format before sending

### Transfer from IOS Mobile Devices

Voice Memos on IOS devices is a good way to quickly record sound. Make sure to export or share the recording with the Save to Files option.
Generally, IOS Voice Memos export standard recordings as .m4a by default.

Transfer the recorded file with:

- AirDrop
- iCloud Drive
- Google Drive/OneDrive/Dropbox
- another file-storage service
- USB/File transfer where appropriate

### Transfer from Android Mobile Devices

Android recording applications vary, so use the app that provides access to the original audio recording.
For example, the Google Pixel Recorder app allows the sharing of recorded audio as a file that can be saved to another app or the internal storage of the device before being transferred to a laptop.

For most Android phones:

1. Record with the audio recording app
2. Share/Export the audio file
3. Transfer the original Audio/File
   - Google Drive/OneDrive/Dropbox
   - another file-storage service
   - USB/File transfer where appropriate
